# 🤖 PDFMind AI

An AI-powered PDF Chatbot built with Python, Streamlit, LangChain, Ollama, and ChromaDB.

## 🚀 Features

- 📄 Upload PDF files
- 🤖 AI PDF Chat
- 📚 PDF Summarization
- 🔍 Semantic Search
- 💬 Chat History
- ⚡ Local LLM (Llama 3.2)
- 🧠 Chroma Vector Database
- 🎨 Modern UI

---

## 🛠 Tech Stack

- Python
- Streamlit
- LangChain
- Ollama
- ChromaDB
- PyPDF

---

## 📦 Installation

```bash
git clone https://github.com/Dhanrajsamal/PDFind-AI.git
```

```bash
cd PDFind-AI
```

```bash
pip install -r requirements.txt
```

```bash
ollama pull llama3.2:3b
```

```bash
ollama pull nomic-embed-text
```

```bash
streamlit run app.py
```
